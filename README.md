# Traffic Accident Risk Analytics Database

## Application Domain
This project focuses on trends in traffic accidents in the US. It aims to further improve understanding of factors that cause traffic accidents.

## Project Scope
The goal of this project is to design a database that is used to store the data of traffic accident records. This database will include variables like weather, location, and accident severity.

The scope of this project is data storage, query optimization, and proper analytics.
